# MessageAgent

MessageAgent is a beta WhatsApp Web desktop agent created by Chris.

It helps manage chats, messages, contacts, groups, unread message notifications, sender detection, and multiple interface languages.

## Features

- WhatsApp Web automation
- `IO` and contact sender detection
- Unread message counters
- Chat search
- Italian, Romanian, and English interface
- Sticker, GIF, audio, and emoji filtering
- Windows installer
- Automatic browser background mode

## Installation

Download `MessageAgentSetup.exe` from the Releases section and run it as administrator.

The installer includes all required files and Playwright browser components. Python is not required.

## Usage

Launch MessageAgent from the Start Menu or desktop shortcut.

Available commands:

- `/help`
- `/chat`
- `/search <name>`
- `/lang`
- `/logout`
- `/exit`

## Beta Notice

MessageAgent is still in beta. WhatsApp Web may change its interface, so some features may occasionally stop working.

If you find a bug, please report what happened, what you expected, and include the error log if possible.

Thank you for trying MessageAgent and for helping improve it.
